# Direktori File Gambar Produk Fernova

Taruh file gambar / mockup produk digital Anda di folder ini (`public/images/products/`).

### Format yang Disarankan:
- **Format:** `.jpg`, `.png`, `.webp`
- **Rasio Aspek:** 16:9 atau 1:1 (contoh: 1000x800 px atau 1000x1000 px)
- **Kompresi:** Usahakan ukuran per file di bawah 400 KB.

### Cara Penggunaan:
1. Simpan gambar di sini, contoh: `template-fernova.jpg`
2. Di database produk (`data/products.json`) atau form input produk di web, masukkan path:
   ```json
   "image": "/images/products/template-fernova.jpg"
   ```
3. Gambar akan langsung otomatis tampil di bagian katalog / store produk FERNOVA!

# Direktori File Gambar Portofolio

Taruh file gambar karya dan proyek Anda di folder ini (`public/images/portfolio/`).

### Format yang Disarankan:
- **Format:** `.jpg`, `.png`, `.webp`
- **Rasio Aspek:** 16:9 atau 4:3 (contoh: 1200x800 px atau 1920x1080 px)
- **Kompresi:** Usahakan ukuran per file di bawah 500 KB agar website tetap super cepat.

### Cara Penggunaan:
1. Simpan gambar di sini, contoh: `project1.jpg`
2. Di data portofolio (`data/portfolio.json`) atau form modal, masukkan path:
   ```json
   "image": "/images/portfolio/project1.jpg"
   ```
3. Gambar akan langsung otomatis tampil di website!

# Foto Profil / Avatar 3D FERNOVA

Foto di folder ini ditampilkan secara langsung sebagai **objek 3D interaktif** di bagian Hero website!

### Cara Mengganti Foto Anda:
1. Siapkan foto Anda (portrait, rasio 3:4 atau 1:1, contoh: 800x1000 px atau 1000x1000 px).
2. Simpan atau timpa file di folder ini dengan nama:
   ```
   ferdinand.jpg
   ```
   *(Bisa juga format `.png` atau `.webp`)*
3. Foto akan otomatis berubah menjadi objek 3D interaktif di hero section dengan efek pencahayaan studio, refleksi kaca, dan rotasi responsif terhadap kursor mouse!
